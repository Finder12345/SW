# TOOLS.md — 工具使用备注

> 这个文件不控制工具的可用性，而是你（用户）对工具使用方式的指导。
> Agent 的工具列表由系统自动提供。

## 文件操作
- 在 ~/workspace 下工作，不要修改 ~/workspace 以外的文件
- 创建文件前先检查是否已存在同名文件

## 网络搜索
- 搜索时优先使用谷歌浏览器
- 技术问题优先查官方文档，不要用论坛帖子

## 代码执行
- 执行 shell 命令前评估风险等级
- 高风险命令（rm、chmod、网络请求）必须先展示给我确认
- pip install 使用 --user 标志

## 消息发送
- 未经确认不发送任何外部消息（邮件、Slack、微信等）
- 发送前必须展示完整消息内容供审核
